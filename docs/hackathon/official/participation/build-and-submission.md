# Build and submission

Checked: 2026-10-06. Source: [official challenges and requirements](https://aibuildercup.com/themes.html).

## Six themes

| Area | Possible focus |
| --- | --- |
| Finance and insurance | Risk, fraud, automation, customer services |
| Retail and commerce | Discovery, personalization, inventory, demand |
| Manufacturing | Quality, reliability, efficiency, sustainability |
| Media and digital content | Creation, discovery, personalized experiences |
| Enterprise productivity | Knowledge access, collaboration, workflows |
| Sustainability and societal benefit | Resources, accessibility, resilience, communities |

## Checklist

- [ ] Deliver a functioning prototype addressing the chosen problem.
- [ ] Use Google AI models, such as Gemini/Gemma, or listed agent platforms, such as Agent Platform, Antigravity, or AI Studio.
- [ ] Deploy using Cloud Run or Firebase on Google Cloud.
- [ ] Explain the problem, benefits, feasibility, and scaling potential in a deck exported to PDF.
- [ ] Provide a public demonstration through YouTube, Vimeo, or Google Drive.
- [ ] Prepare English code, documentation, and presentations.
- [ ] Check the additional [FAQ deliverables](eligibility-and-faqs.md).

| Dimension | Weight |
