## 1. Goal

A deployed, benchmarked **AIRA** that lets a blind shopkeeper (Murugan Dairy: Aavin milk, Sakthi curd, Arun ice cream) run the core shop loop alone:

```
order → live count → invoice check → pay vendor → guided sale → cash/UPI check → stock → reorder
```

The submission also needs a **4-minute video (target 3:50)**, a PDF deck, and a description of 1024 characters or fewer that names **Firebase, Firestore, Cloud Run and Gemini**.

The rules text says "3 to 4 minute video", but the form label says "up to 3 minutes". Saravana confirms the length with support@hack2skill.com before upload.

The earlier multi-pillar concept is dropped.

## 8. Definition of done: must-work core

All of these work on the deployed link with the real phone:

| Spec §2 step | Done when |
|---|---|
| 1. Order | "Order 30 L Sakthi curd" → read-back → "yes" → WhatsApp message received by the vendor phone → the vendor's reply is spoken. Order state `ORDER_PLACED` |
| 2. Delivery count | One-by-one count with live `count` messages, plus crate mode. A 2-short case is recorded as `DISCREPANCY`; only the verified quantity enters the ledger |
| 3. Invoice | Two reads + code compare. A mismatching invoice (for example 32 L billed, 30 counted) is caught and spoken |
| 4. Pay vendor | Cash notes read, total checked by code, confirm → `PAYMENT_CONFIRMED` |
| 6. Customer sale | "2 litres curd" → stock check → hand guided to the pack (location memory + `point_to` + fingertip tones) → pack identified → price spoken |
| 7. Payment | Cash: notes read + `change_due` spoken. UPI: a soundbox clip is parsed and the amount matched. `SALE_COMPLETED`; stock drops **exactly once**, including on a retried tool call |

Also required:

- **Shop Dashboard** shows live stock, today's sales, orders and deliveries, discrepancies and the audit trail.
- **Judge demo mode** runs the whole loop on a laptop with bundled sample media (videos, invoice and cash images, soundbox audio).
- **Next priority, not core:** spec steps 5 (remember location by voice), 8 (low stock / expiry) and 9 (end-of-day summary + forecast).
